NEON NEKO CAFÉ

Kiko runs the coziest cat girl café in the megacity. Pet her, hire a neon crew, and build a café empire across six districts.

WINDOWS EDITION

The same café as a native Windows game: one small EXE, no installer, no DirectX, nothing else to download. Built to run on everything from Windows 95 to Windows 11.

Download for WindowsNeonNekoCafe-Windows.zip · 172 KB · NeonNekoCafe.exe + README

Unzip and double-click NeonNekoCafe.exe. Windows 10/11 may warn that the app is unrecognised because it isn't code-signed: choose More info, then Run anyway.

What's in it

  • The full game: staff, upgrade tree, customers, Purr Frenzies, relocating across six districts, achievements
  • Kiko's Jukebox with five visualizers fed by the real audio
  • Attract-mode demo, Kiko's "Nyaa~!", and the secret codes
  • No menus or chrome: window size 1×–4× (F9), 4:3 CRT picture or square pixels (F8), full screen with Alt+Enter, all keys on F1
  • Saves to %APPDATA%\NeonNekoCafe

Under the hood

Native Win32 built with Open Watcom C. It shares its game code with the MS-DOS edition: the same 320×200 picture is scaled with GDI, the same chiptune synth streams through waveOut on its own thread, and the art is packed inside the EXE.
